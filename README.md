# ระบบตัดสต็อกหนังสือ

เว็บสำหรับจัดการสต็อกหนังสือ ใช้งานได้จากไฟล์ `index.html` ไฟล์เดียว

- บันทึกหนังสือแยกตามหมวด พร้อมจำนวนทั้งหมด ใช้ไป และคงเหลือ
- รับเข้าสต็อก พร้อมวันที่รับเข้า
- ตัดสต็อกเป็นใบเบิก ใส่หนังสือได้หลายรายการ ระบุชื่อผู้เบิกและวันที่
- คืนหนังสือเข้าสต็อกจากใบเบิก
- สรุปใบเบิกแยกตามระดับชั้น (อ่านจากชื่อหนังสือ เช่น ป.1, ม.2) และสรุปรายผู้เบิก
- ดาวน์โหลดใบเบิกและสรุปเป็นไฟล์ PDF

## การใช้งาน

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ หรือเปิด GitHub Pages ของ repo นี้

ข้อมูลจะบันทึกไว้ในเบราว์เซอร์ของเครื่องที่ใช้งาน (localStorage) เท่านั้น
ถ้าเปิดจากเครื่องอื่น หรือล้างข้อมูลเบราว์เซอร์ จะไม่เห็นข้อมูลชุดเดิม
